# Add to Applications 0.1.0

Add a standalone executable to GNOME Applications from its right-click menu in
Files. Press Super and search for it alongside installed apps.

## Features

- One-click Add action, with automatic name and optional nearby icon.
- Rename and remove from the same file's context menu.
- Notification Undo, including after the helper exits.
- Per-user installation with a matching uninstaller.

## Compatibility

Targets GNOME 51 / Files 51 and Nautilus API 4.1. Requires Python 3.11+,
PyGObject, nautilus-python, GTK 4, and libadwaita. This is a Files extension;
it is not installed through extensions.gnome.org.

The owner has tested the functionality on their GNOME desktop and confirmed the
expected behavior. Automated validation covers the actual embedded Python loader,
desktop launcher behavior, notifications, Undo, native rename UI and packaging.
See `docs/VALIDATION.md` for the exact scope of testing.

## Install and remove

Download the source archive attached to this release and extract it. Install the
distribution dependencies listed in `README.md`, then run from the extracted folder:

```sh
python3 tools/install.py
```

Restart Files to load the action. To remove it, run from the same folder:

```sh
python3 tools/install.py --uninstall
```

Restart Files again to unload it. Executable files and existing application
shortcuts are preserved. Remove test shortcuts through their file's context menu
before uninstalling if you want those shortcuts cleaned up too.

## Limitations

Executables stay where they are; moving or deleting them can break their shortcuts.
Programs launch without a terminal. The interface is currently English. Native
distribution packages are not included in this initial source release.
